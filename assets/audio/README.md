# Nhạc nền Trung thu

Thả file nhạc của bạn vào thư mục này với tên: **bgm-trungthu.mp3**

(Đường dẫn đầy đủ: `assets/audio/bgm-trungthu.mp3`)

Yêu cầu:
- Định dạng .mp3 (tương thích rộng nhất trên trình duyệt/di động)
- Nên là nhạc không lời hoặc nhạc nền nhẹ, âm lượng vừa phải, vì sẽ phát
  suốt quá trình giải đố (loop liên tục)
- Đảm bảo bạn có bản quyền / được phép sử dụng cho mục đích này (nhạc miễn
  phí bản quyền, nhạc tự sáng tác, hoặc đã mua license phù hợp)

Nếu không có file này, trang vẫn chạy bình thường — chỉ đơn giản là không
có nhạc nền (không lỗi, không cảnh báo với người chơi).

Muốn đổi tên file hoặc dùng nhiều bài luân phiên? Sửa trong `js/audio.js`,
phần `BGM_SRC`.
